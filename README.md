# Happy Beans Coffee — Churn Prediction

Проект посвящён прогнозированию оттока клиентов сервиса Happy Beans Coffee.

## Состав проекта

- `coffee_churn_project.ipynb` — Jupyter Notebook с решением.
- `requirements.txt` — версии библиотек для воспроизводимости окружения.
- `coffee_churn_artifacts` — папка с production-артефактами модели.
